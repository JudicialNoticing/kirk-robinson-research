**Method note.** "Tier 1" per the project framework means sworn testimony and primary documents. This roadmap distinguishes three pull categories honestly rather than inflating everything to Tier 1:
- **[T1]** true primary documents (court files, vital records, corporate/state filings, government disclosures, published disciplinary opinions, legislative records, registry data);
- **[PA]** primary *artifacts* of a person's own statements (archived web pages, posted videos, social posts) — Tier 2 as statements, but the pull secures the artifact itself rather than a paraphrase;
- **[T3]** named-press items pulled only to fix exact wording (e.g., the NYT profile).

Each target lists: custodian → mechanism → cost/friction → what it tests (claims + register cross-refs) → outcome branches where decisive. Outcome branches are stated in both directions; the roadmap's purpose is verification, not confirmation.
